# Open Food Facts

[Open Food Facts](https://world.openfoodfacts.org) — free, open database
of food products from around the world (ingredients, nutrition facts,
labels, etc.), crowdsourced like a "Wikipedia for food".

## Base URL

```
https://world.openfoodfacts.org/api/v0/product
```

Look up a product by barcode:

```
GET https://world.openfoodfacts.org/api/v0/product/<barcode>.json
```
